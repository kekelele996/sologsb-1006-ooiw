# 会议同传提示台

面向会议管理员和同传人员的现场提示台。后台准备内容与现场可见内容明确分离，支持实时队列、术语提醒、紧急通知以及断网手工录入。

## 功能

- 维护演讲顺序、发言人、语言方向、术语表和紧急通知。
- 每场登记计划时长；管理员在现场页登记某场实际结束时刻后，后续未开始场次自动顺延或提前重排，原计划时间始终保留对照。
- 顺延遇午休/茶歇或时间锁定场次即停，明确标出阻挡点及其后保持原计划的安排，并提示对锁定点的挤压分钟数。
- 每次重排生成留痕（锚点、偏差、受影响场次、锁定点），与现场预计时间一起保存在本机，重开页面仍可沿同一次调整查看；可一键恢复原计划。
- 自动接入现场文字并进入后传译队列；可手动模拟下一段。
- 逐条确认已传、补充遗漏、标记待跟进和清理重复提醒。
- 基于字符二元组相似度检测重复内容；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法、术语提醒和“已看到”确认。
- 紧急通知先保存后台，管理员明确发布后才进入现场可见区。
- 网络中断时继续手工录入本机暂存；恢复后合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号。
- 浏览器本地持久化、撤销重做与字号偏好恢复。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示，所有管理员配置、现场队列和暂存内容保存在当前浏览器。清理站点数据会移除本地记录。
